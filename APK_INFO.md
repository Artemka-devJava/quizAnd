## 🚀 Установка APK на устройство

### Способ 1: Android Studio
1. Откройте Android Studio
2. Перейдите в `Run` → `Run 'app'`
3. Выберите устройство или эмулятор
4. Приложение установится автоматически

### Способ 2: adb (Android Debug Bridge)
```bash
# Для release версии
adb install app/build/outputs/apk/release/app-release-unsigned.apk

# Или для debug версии
adb install app/build/outputs/apk/debug/app-debug.apk
```

### Способ 3: Прямая установка
1. Скопируйте APK файл на Android устройство
2. Откройте файловый менеджер на устройстве
3. Нажмите на APK файл
4. Подтвердите установку
5. Разрешите установку из неизвестных источников (если требуется)

## 🎯 Использование приложения

### Для Ведущего:
1. Запустите приложение
2. Выберите роль "Ведущий"
3. Введите ник и порт
4. Нажмите "Запустить сервер"
5. Дождитесь подключения игроков
6. Нажмите "Начать игру"
7. Управляйте раундами и оридите ответы

### Для Игрока:
1. Запустите приложение
2. Выберите роль "Игрок"
3. Введите свой ник
4. Нажмите "Подключиться"
5. Выберите сервер из списка
6. Ждите начала игры
7. Нажимайте "BUZZ!" чтоб ответить
